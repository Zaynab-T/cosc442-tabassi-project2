## Parameterized Test

insertMoney is tested with @ValueSource(doubles = {0.0, 0.01, 0.25, 0.99, 1.0, 5.0}). The values were chosen to cover the boundary at 0 (exactly 0 and just above it), amounts below one dollar (like coins), exactly one dollar, and a larger amount. Each value starts from a new machine, so the expected balance equals the amount inserted. Negative amounts are tested separately with assertThrows.
